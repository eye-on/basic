# 外部视觉观测协议

当前 `football_robot` 将外部板子视为“观测源”，而不是“配置源”。

也就是说，外部板子只发送它自己能够直接观测到的数据，例如：

- 时间戳
- 图像宽高
- 当前识别出的颜色类别
- 检测类别 id
- 置信度
- 检测框像素坐标

以下内容不再由外部板子发送，而是保留在 VEX 本地配置中：

- 相机内参
- 相机外参
- 球的实际直径
- VEX 侧估计器参数

## 串口参数

- 波特率：`115200`
- 端口：`PORT20`
- 传输方式：ASCII 文本行协议
- 换行：以 `\n` 结尾，前面可带 `\r`

每一行表示一帧完整观测，格式如下：

```text
OBS,source_timestamp_ms,has_detection,color_code,class_id,score,image_width_px,image_height_px,x,y,width,height
```

## 字段说明

- `source_timestamp_ms`
  - 外部板子生成的时间戳
  - 单位：毫秒
  - 建议使用“自启动以来的单调时间”

- `has_detection`
  - `0` 表示这一帧没有有效目标
  - `1` 表示这一帧存在有效目标

- `color_code`
  - 外部板子当前识别出的目标颜色
  - 当前支持：
  - `R`：红色
  - `Y`：黄绿
  - `P`：紫色

- `class_id`
  - 检测器输出的类别 id
  - 当 `has_detection=0` 时，建议发送 `-1`

- `score`
  - 检测置信度
  - 建议范围：`0.0` 到 `1.0`

- `image_width_px`, `image_height_px`
  - 当前这帧检测所使用的图像尺寸
  - 单位：像素

- `x`, `y`, `width`, `height`
  - 检测框像素坐标
  - `x`, `y` 为左上角
  - `width`, `height` 为框宽和框高
  - 当 `has_detection=0` 时，这四个值建议发 `0`

## 报文示例

检测到目标：

```text
OBS,1532,1,R,0,0.93,640,480,278,164,96,94
```

没有目标：

```text
OBS,1548,0,R,-1,0.00,640,480,0,0,0,0
```

识别到紫色目标：

```text
OBS,2017,1,P,2,0.88,640,480,301,146,84,83
```

## VEX 侧当前行为

- 每收到一条合法的 `OBS` 报文，就更新一次当前外部视觉状态
- `color_code` 会更新机器人当前目标颜色状态
- 图像尺寸和检测框会送入当前单目估计流程
- 相机内参、外参、球直径仍然从 VEX 本地配置读取
- 如果大约 `500 ms` 内没有收到新的观测，当前目标会被判定为过期

## 外部板发送示例

```cpp
Serial.println("OBS,1532,1,R,0,0.93,640,480,278,164,96,94");
Serial.println("OBS,1548,0,R,-1,0.00,640,480,0,0,0,0");
```
