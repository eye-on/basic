Offline Helper

相机标定工具页

这个页面不直接做 OpenCV 标定。它负责整理参数、生成命令、读取 `calibration_result.json`、判断误差是否合理，并生成你要抄回项目里的代码片段。

推荐流程

  1. 用外部板子的摄像头拍 20 到 40 张棋盘格照片。
  2. 把照片导到电脑，放进一个目录。
  3. 运行 `calibrate_camera.py` 生成 JSON 和去畸变预览。
  4. 把 `repo_snippet.txt` 里的参数抄回项目配置。

不建议

  • 不要用投影棋盘格做最终标定。
  • 不要只靠检测框坐标做标定。
  • 不要让标定模式和实战模式分辨率不一致。

5. 怎么判断“更直”

          
    
            
  • 先看 `undistort_previews` 目录里的对比图，尤其是边缘直线。
    • 
            
  • 门框、白板边、桌沿、棋盘格边线，去畸变后应更接近直线。
    • 
            
  • 原图如果是桶形畸变，边缘会向外鼓；矫正后应明显收回来。
    • 
            
  • 正式判断不要只看中间，必须看四角。
    • 
          

        


        

          
6. 结果解释

          
    
            
  • `RMS < 0.5 px`：通常很好。
    • 
            
  • `0.5 ~ 1.0 px`：大多可用，但建议看预览图再决定。
    • 
            
  • `> 1.0 px`：往往要重拍，先检查模糊、反光、覆盖范围不够等问题。
    • 
            
  • 如果板子检测前做了裁剪或 letterbox，务必确认框坐标和标定图像坐标系一致。
